# Groq AI para NVDA

Complemento para NVDA que usa Groq AI.

## Descargar
- Descarga directa del complemento (.nvda-addon):
  https://github.com/elgamer780/groq-ai-para-nvda/releases/latest/download/GrokAI-2026.1.3.0.2.nvda-addon
- Instálalo desde NVDA: menú NVDA > Herramientas > Administrador de complementos > Instalar desde archivo.

## Versiones
- Los cambios de cada versión están en el repositorio y en los lanzamientos (Releases).

## Código fuente
- Los complementos de NVDA son archivos ZIP; el .nvda-addon contiene el código.
